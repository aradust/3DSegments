## Программа на C++ для определения пересечения векторов в 3D

## Описание программы

Программа предназначена для определения пересечения двух отрезков в трехмерном пространстве. Входными данными для программы являются координаты концов двух отрезков, представленных в виде векторов. Программа должна вычислить, пересекаются ли эти отрезки в пространстве.

### Задача
Каждый отрезок в трехмерном пространстве можно представить как два вектора, которые определяют его начало и конец. Для каждого из двух отрезков (A1, A2 и B1, B2) нужно проверить, пересекаются ли они.
